# PwDftScfEnergyAlignment

- `result` is a completed, converged SCF result.
- `kind` declares native or explicit-reference treatment.
- `reference_energy_ev_per_atom` is subtracted from the native energy.
- `reference_id` identifies external reference evidence.
- `qualification` bounds interpretation of that reference.
- `native_energy_ev_per_atom` exposes the unchanged observation.
- `aligned_energy_ev_per_atom` exposes the explicitly adjusted value.
