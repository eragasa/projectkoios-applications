# PwDftScfComparisonAnalysis

- `request` preserves the exact comparison inputs.
- `interpretation` bounds the scientific claim.
- `native_left_minus_right_mev_per_atom` preserves the native difference.
- `aligned_left_minus_right_mev_per_atom` records the declared aligned difference.
- `irreducible_kpoint_counts_match` reports comparable observed counts when present.
- `wavefunction_cutoff_left_minus_right_ev` reports the observed cutoff difference when present.
- `qualifications` records mandatory and reference-specific limitations.
